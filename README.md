# 🎮 KenTyping - Learn Typing While Having Fun!

A colorful and engaging typing tutor app designed specifically for children (6+) and young learners to master keyboard typing through interactive games and exercises.

## 🚀 Features

### 1. **Typing Test** ⌨️
- Multiple difficulty levels from beginner to advanced
- Real-time WPM (Words Per Minute) calculation
- Accuracy tracking
- Progress visualization
- Immediate feedback

### 2. **Interactive Games** 🎮
Three exciting games that make learning fun:

- **🦖 Dinosaur Jump Game**: Jump over falling letters using the SPACE key
- **👾 Pacman Letter Game**: Move mouse to eat falling letters and words
- **🎖️ Tank Word Battle**: Type words to destroy incoming enemies

### 3. **Practice Mode** 📚
- Organized word lists by level
- Learn new vocabulary at your own pace
- Visual word cards for memorization

### 4. **Statistics Dashboard** 📊
- Track total tests completed
- Average WPM statistics
- Accuracy metrics
- Games played counter
- Achievements system with badges

## 🌈 Design Features

- **Vibrant Colorful Graphics**: Rainbow gradients and animated backgrounds to keep children engaged
- **Smooth Animations**: Bounce-in effects, floating text, and glow animations
- **Kid-Friendly Interface**: Large buttons, clear instructions, emoji indicators
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Cross-Platform**: Works on Windows, Mac, and Linux

## 🛠️ Tech Stack

- **Frontend**: React 19 + Vite
- **Styling**: Tailwind CSS 4 + Custom CSS animations
- **Canvas Graphics**: HTML5 Canvas for interactive games
- **Deployment**: GitHub Pages

## 📦 Installation

### Prerequisites
- Node.js 16+ 
- npm or yarn

### Setup

```bash
# Clone the repository
git clone https://github.com/uandrb/kentyping.git
cd kentyping

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```

## 🎯 Game Levels

- **Beginner**: Single letters (A-P)
- **Level 1**: Animals & Nature words
- **Level 2**: Common everyday words
- **Level 3**: Advanced & longer words

## 📖 How to Use

1. **Start the App**: Open in browser at `http://localhost:5173` (dev) or GitHub Pages link
2. **Choose Mode**:
   - Typing Test: Take timed typing tests
   - Games: Play interactive games
   - Practice: Learn words at your pace
   - Stats: View your progress
3. **Follow On-Screen Instructions**: Each activity has clear guidance
4. **Track Progress**: Monitor improvement in the Stats dashboard

## 📊 Typing Test Metrics

- **WPM** (Words Per Minute): Measures typing speed
- **Accuracy**: Percentage of correctly typed words
- **Time per Word**: Average time spent on each word
- **Progress Bar**: Visual representation of test completion

## 🎮 Game Rules

### Dinosaur Jump
- Press SPACE to make dinosaur jump
- Avoid falling word obstacles
- Higher score = more words avoided

### Pacman Letters
- Move mouse to control Pacman
- Eat all the falling letters
- Score increases with each letter collected

### Tank Battle
- Use arrow keys to move the tank
- Type the displayed words to fire at enemies
- Destroy all enemies to win
